## Démarrage rapide / Quick Start

```bash
# Cloner le repository / Clone the repository
git clone https://github.com/ErrorNoName/KillerBunny.git
cd KillerBunny

# Lancer le jeu / Run the game
python bunny_adventure/game.py

# Exécuter les tests / Run tests
python -m pytest tests/

# Ouvrir l'interface web / Open web interface
open web_interface/index.html
```
